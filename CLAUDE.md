# Instruções do projeto

- Sempre que uma branch `claude/...` for finalizada e enviada (push), abrir o
  pull request e fazer o merge para `main` automaticamente, sem esperar
  confirmação do usuário para esse passo específico. O usuário baixa o
  projeto direto do `main` como ZIP no GitHub, então o `main` precisa estar
  sempre atualizado com as correções mais recentes.
